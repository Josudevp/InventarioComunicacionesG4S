# Imagenes de accesorios

Agrega aqui una imagen por articulo usando su SKU como nombre de archivo. Se aceptan guiones o guiones bajos:

- `FOR-G06.png`
- `VID-G22.jpg`
- `CARG-TIPOC.webp`
- `FOR_G08.webp`

La aplicacion busca automaticamente en este orden: `.png`, `.jpg`, `.jpeg`, `.webp`.
El SKU debe coincidir con la columna `ID` del `Maestro de inventario`. La aplicacion tambien prueba la variante con `-` cambiado por `_`.

Haz clic sobre la miniatura del catalogo para verla ampliada. No es necesario modificar `index.html` ni subir imagenes a Drive. Despues de agregar archivos, recarga la aplicacion.
